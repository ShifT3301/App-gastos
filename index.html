    Sobre e limitações
    • Seus dados ficam só no seu computador. Não há servidor: tudo é lido e gravado num arquivo .json que você escolhe.
    • Salvar direto no arquivo só funciona no Chrome e no Edge (File System Access API). No Firefox e no Safari, use Abrir para importar e Salvar para baixar o JSON atualizado — depois substitua o arquivo antigo por ele.
    • Sem sincronização automática entre dispositivos: o arquivo é a única fonte de verdade. Para usar em outro aparelho, mova o arquivo (por exemplo, pelo Google Drive).
    • Abrindo o .html direto do disco (file://), alguns navegadores restringem permissões. Se algo não funcionar, rode um servidor local simples na pasta do app, por exemplo python3 -m http.server, e acesse http://localhost:8000.
    • A detecção de “gasto fútil” é uma busca simples por palavras-chave, não inteligência artificial. Pode errar (ex.: “bar” também aparece em “barbeiro”). Você sempre pode aceitar, recusar ou corrigir manualmente, e editar as palavras-chave em ⚙️ Configurações.
    • Como segurança extra, alterações ainda não salvas ficam guardadas como rascunho neste navegador até você salvar.
